Моё личное настольное приложение с ИИ. Написано на Rust для macOS, с нативным интерфейсом на [Rune](https://github.com/anomalyco/rune) и бэкендом [IronClaw](https://github.com/nearai/ironclaw).

Я [Lorik](https://github.com/RiklloD). Я студент бизнес-направления и люблю возиться с техникой. Идей у меня больше, чем инженерного опыта, поэтому я работаю с ИИ-агентами, чтобы превращать эти идеи в программы, которыми могу пользоваться. ZLO — приложение, которое я строю вокруг такого способа работы.

## Зачем я его делаю

Настольное приложение для меня так же важно, как агент за ним. Я хочу что-то лёгкое, что ощущается на Mac как родное. Расход памяти и время работы от батареи — часть продукта, а не то, что исправляют после добавления всех функций.

Это моя собственная рабочая среда и место для проверки идей. Это не обещание отполированного релиза или поддержки любой машины.

## Что оно умеет

- **Нативный интерфейс.** Rust с GPU-отрисовкой на Rune. Никакого Electron и никакого постоянно запущенного встроенного браузера; окна браузера и документов создаются только когда нужны.
- **Чаты, профили и модели.** Выбирайте модель под задачу, держите отдельные профили и передавайте работу другим агентам через оркестратор, включая Codex и Claude Code.
- **Инструменты, навыки, память и MCP** через бэкенд IronClaw.
- **Управление компьютером** через мой форк [движка computer-use](https://github.com/RiklloD/hermes-plugin-computer-use-plus).
- **Подтверждения.** Каждый профиль либо сначала спрашивает, либо получает полный доступ. Автоматическое подтверждение по умолчанию выключено.
- **Работа на других компьютерах.** Бэкенд может работать на другой машине, например на Mac mini или Linux-сервере, а ZLO на ноутбуке остаётся только окном. Машины соединяются через Tailscale или SSH. См. [Использование другого компьютера](tools/ironclaw_rune/docs/remote-computers.md).

Я меняю приложение по мере использования. Код и заметки разработки лучше описывают его текущее состояние, чем фиксированный список функций.

## Как это работает

У ZLO две половины: **окно** (приложение на Rune) и **бэкенд** (IronClaw, который запускает агента, его инструменты и память). Они общаются по HTTP с аутентификацией. Где работает бэкенд, решаете вы:

| Вариант | Что где работает | Когда использовать |
| --- | --- | --- |
| **Всё на этом Mac** (по умолчанию) | ZLO запускает собственный бэкенд как дочерний процесс и останавливает его при выходе. | Одна машина, ничего настраивать не нужно. |
| **Бэкенд на другом компьютере** | Бэкенд работает на сервере или другом Mac. ZLO подключается к нему через ваш tailnet или SSH. | Чтобы агент продолжал работать, пока ноутбук спит, или чтобы работать на машине мощнее, с вашими репозиториями или с лучшим подключением. |
| **Только приложение** (ZLO Light) | Сборка ZLO без встроенного бэкенда. Она всегда подключается только к другим компьютерам. | Ноутбук, на котором агенты сами запускаться не должны. |

Переключаться между компьютерами можно в **Settings → Computers**. ZLO работает с одним компьютером за раз. У каждого компьютера свои треды, память, настройки и ключи провайдеров, потому что они хранятся вместе с его бэкендом.

Состояние хранится в `~/.zlo` на той машине, где работает бэкенд (задайте `ZLO_HOME`, чтобы хранить его в другом месте), в libSQL, а не на отдельном сервере PostgreSQL. Каталог `~/.ironclaw/reborn` от старой установки переносится туда при первом запуске, а старый путь остаётся ссылкой, так что ничего, что его помнит, не ломается.

Локальное хранение не значит, что каждая задача остаётся на машине. При использовании удалённой модели или внешней интеграции данные, нужные для запроса, отправляются этому провайдеру. Для управления компьютером нужны соответствующие разрешения macOS на машине, где работает бэкенд.

## Установка

На Mac с Apple Silicon вставьте это в Терминал:

```sh
curl -fsSL https://raw.githubusercontent.com/RiklloD/ZLO/main/install.sh | sh
```

Скрипт собирает ZLO из исходников и устанавливает в `~/Applications/ZLO.app`. Если нет инструментов командной строки Xcode, он открывает их установщик и просит запустить команду снова. Если нет Rust, он его устанавливает. Первая сборка занимает от 10 до 20 минут. Для обновления запустите ту же команду ещё раз.

Чтобы собрать ветку, отличную от `main`, задайте `ZLO_REF`:

```sh
curl -fsSL https://raw.githubusercontent.com/RiklloD/ZLO/main/install.sh | ZLO_REF=my-branch sh
```

Без подписи Apple Development приложение подписывается ad-hoc, поэтому после каждого обновления macOS снова запрашивает доступ к универсальному доступу и записи экрана.

## Использование другого компьютера

Краткая версия для сервера в вашем tailnet:

```sh
# На сервере
zlo onboard            # провайдеры и ключи
zlo service install    # запуск при загрузке
zlo remote enable      # опубликовать в tailnet (никогда не в интернет)
zlo service restart
```

Затем откройте ZLO на Mac, перейдите в **Settings → Computers** и нажмите **Connect** рядом с сервером в разделе «Found on your tailnet».

[**Использование другого компьютера**](tools/ironclaw_rune/docs/remote-computers.md) описывает всю настройку:

- настройка Linux-сервера или второго Mac;
- сопряжение в один клик, по коду или через SSH;
- управление сопряжёнными устройствами;
- перенос вашей среды (треды, память, профили, настройки, ключи провайдеров) на сервер с помощью `zlo transfer user@host` или `zlo export` / `zlo import`;
- что работает удалённо;
- как защищено соединение;
- устранение неполадок.

[**Обновление машин**](tools/ironclaw_rune/docs/updates.md) объясняет «Update all machines» и `zlo update`.

## Сборка из исходников

Это среда разработки для macOS, а не кроссплатформенный установщик. Нужны инструменты командной строки Xcode, Rust через rustup и подпись Apple Development. Репозиторий фиксирует версию Rust в [`rust-toolchain.toml`](rust-toolchain.toml). Встроенный движок computer-use сейчас рассчитан на Apple Silicon.

```sh
git clone https://github.com/RiklloD/ZLO.git
cd zlo
sh tools/ironclaw_rune/bundle.sh
```

Скрипт собирает бэкенд и настольное приложение, скачивает и проверяет закреплённую версию движка computer-use, подписывает пакет и устанавливает его в `~/Applications/ZLO.app`. Он заменяет существующую установку: если приложение запущено, сначала закрывает его, и снова открывает, если оно было открыто.

| Команда | Результат |
| --- | --- |
| `sh tools/ironclaw_rune/bundle.sh` | Собрать, установить в `~/Applications/ZLO.app`, открыть снова |
| `sh tools/ironclaw_rune/bundle.sh --no-install` | Только собрать, в `tools/ironclaw_rune/target/ZLO.app` |
| `sh tools/ironclaw_rune/bundle.sh --light` | Собрать и установить **ZLO Light.app** без бэкенда и без движка computer-use. Это отдельное приложение, поэтому оно никогда не заменяет ZLO. |

Отдельно бэкенд (для сервера) собирается так:

```sh
cargo build --release -p ironclaw     # бинарный файл в target/release/zlo
```

Для изменений в настольной рабочей области:

```sh
cd tools/ironclaw_rune
cargo check
cargo clippy --all-targets -- -D warnings
cargo test
```

Перед изменением кода бэкенда прочитайте [`AGENTS.md`](AGENTS.md) и указания крейта, которому принадлежит код.

Фронтенд на React, унаследованный от IronClaw, не является настольным интерфейсом ZLO. Шлюз за ним по-прежнему используется.

Команда, которую вы вводите (`zlo`), и папка данных (`~/.zlo`) принадлежат ZLO. Внутренние крейты сохраняют имена IronClaw (`ironclaw_*` и пакет Cargo `ironclaw`, который собирает `zlo`), как и рабочие папки CLI-агентов в `~/.ironclaw/` и некоторые старые идентификаторы подписи Numoh. Их стабильность упрощает слияния с апстримом и поддержку разрешений macOS.

## Откуда это

ZLO — мой личный форк [IronClaw](https://github.com/nearai/ironclaw), созданного [NEAR AI](https://github.com/nearai). Я построил своё настольное приложение на этой основе и продолжаю менять бэкенд под себя. Среда выполнения агента, механизмы безопасности и большая часть этого репозитория — результат их работы.

Интерфейс использует [Rune](https://github.com/anomalyco/rune). Более ранняя версия приложения была построена на [GPUI](https://www.gpui.rs/), UI-фреймворке на Rust, разработанном для Zed; она сохранена в ветке `archive/gpui` (тег `gpui-final`). Помощник computer-use взят из [hermes-plugin-computer-use-plus](https://github.com/RiklloD/hermes-plugin-computer-use-plus). Способ, которым ZLO подключается к другим компьютерам, повторяет удалённые среды [T3 Code](https://github.com/pingdotgg/t3code), с Tailscale вместо их хостингового ретранслятора.

Этот репозиторий — мой проект, а не официальный релиз IronClaw или NEAR AI.
