Keep a visible checklist of your plan for the current task. The person sees it pinned above their message box, with the step you are on highlighted.

Use it when a task takes three or more distinct steps, or when the person gives you several things to do. Skip it for a single quick action or a plain question.

Every call replaces the whole plan: send all entries each time, in order. Mark exactly one entry `in_progress` while you work on it, and mark it `completed` as soon as it is done, before starting the next. Add entries you discover along the way; drop ones that no longer apply. Keep each entry short and concrete ("Add the migration", not "Work on the database"). `active_form` is the step as it reads while running ("Adding the migration").
